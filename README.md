💬 ##ChatApp
What is ChatApp?

ChatApp is a modern, lightweight static chat application designed to simulate real-time messaging and user interaction in the browser. It provides a clean, intuitive interface where users can sign up, sign in, chat with other users, manage their profiles, and experience a responsive chat environment — all using front-end technologies.

ChatApp focuses on simplicity, usability, and UI/UX design while demonstrating real-world application structure, state management, and multi-page navigation using pure web technologies.

🧩 **Components & Functional Requirements**
**1. Authentication Subsystem**

- User can sign up
- User can sign in
- User session is stored locally
- User can log out
- User identity is tracked per session

**2. User / Profile Management**

- User can view profile

**3. Chat / Messaging Subsystem**

**User capabilities:**

- Send messages
- Receive messages
- View chat history
- Select active chat user
- Multi-tab chat synchronization
- Timestamped messages
- Active chat highlighting

**4. Community / Users List Subsystem**

- View list of users
- See online/offline status
- Select users to chat with
- Dynamic user rendering

**5. Local Storage Subsystem**

- Store users data
- Store chat messages
- Store current session
- Store active chat
- Sync data across tabs using storage events

**6. UI / UX Subsystem**

- Responsive layout
- Mobile-friendly design
- Clean chat interface
- Profile UI
- Navigation system
- Modern design patterns

📄 **Pages**

- ChatApp includes the following pages:
- Sign Up Page – account creation
- Sign In Page – user authentication
- Chat Page – messaging interface
- Profile Page – user profile management

⚙️ **How to Run ChatApp (Local Setup)**

1. Download / clone the repository
2. Open index.html in your browser

**🧪 Tech Stack**

- HTML5
- CSS3
- JavaScript (ES6 Modules)
- LocalStorage API
- Browser Storage Events
- Google Fonts
- Material Icons
